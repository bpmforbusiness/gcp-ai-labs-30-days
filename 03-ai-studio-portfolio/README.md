## 🧠 The AI Concept: Vibe Coding with AI Studio

**Building with AI starts with a query, not a blank editor.** Google AI Studio's **Build Mode** is "vibe coding" — you describe an app in natural language, and a Gemini-driven agent writes the code. You iterate by chatting ("style it with Tailwind + dark mode"), then **deploy to Cloud Run with one click** — no Dockerfile, no YAML, no terminal.

**Why it matters:** This is the fastest path from idea → running web app on the internet. It's also a taste of where building is head: the *developer* becomes a product manager + reviewer, and the AI does the implementation. For your positioning (Forward-Deployed AI Engineer), this is exactly the "ship fast with AI" skill enterprise teams want.

## 🛠️ The Build (Step-by-step)

### What you'll build
- A **personal portfolio website** (bio, projects, skills, social links) generated by AI Studio's code agent
- Tested in the **interactive preview sandbox**
- Deployed to **Cloud Run** with one click from the AI Studio UI

### Key steps
1. **Verify prerequisites** — personal Google account + Starter Tier (free, 2 apps, select region) or Standard (paid project)
2. **Create the app:** AI Studio → New App → prompt:
   > *"Build a professional personal portfolio website. The site should have a modern, responsive design and sections for my biography, projects showcase, skills, and links to my professional profiles (e.g., GitHub, LinkedIn)."*
3. **Build** — the agent generates the frontend
4. **Test & iterate** in the preview sandbox — click nav/links/layouts
   - Use the **Fix button** for runtime/compilation errors
   - Iterate via chat: *"Style with Tailwind, add a dark mode toggle"*, *"add a talks/presentations section"*
5. **Deploy:** click **Publish** → configure GCP project → verify service ID → **Publish App** (2-4 min)
6. **Visit the live URL** and test

### Optional
- **Custom domain** — map `yourname.com` / `portfolio.yourname.com` via Cloud Run Domain Mappings + DNS records (A/AAAA for apex, CNAME for subdomain), SSL auto-provisions in ~15 min (up to 24h)

## 💰 Cost & Free Tier

**Starter Tier = free** (up to 2 full-stack apps in a select region, no billing account needed). Standard deployment uses a paid GCP project. Cloud Run is effectively free at low/no traffic.

## ⚠️ Gotchas / Failures
- **Workspace accounts break it** — use a *personal* Google account (corporate/school Workspace policies disable experimental features/cloud integration)
- **Starter vs Standard** — Starter is capped at 2 apps + select regions; Standard needs a paid project
- Runtime/compile errors → use the **Fix** button in chat (don't refresh away from preview)
- Custom domain SSL can take up to 24h for DNS propagation
