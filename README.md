## 📂 Structure

```

├── 01-rag-barista-agent/    ← one folder per lab
│   ├── README.md            ← concept + walkthrough
│   ├── code/                ← code from the lab
│   └── screenshots/         ← proof of the working build

```

## 🧠 How to use this repo

- **Each folder** = one lab day. README explains the AI concept + the exact GCP steps + what broke.
- **`code/`** = the working code from that lab (run it yourself).
- **`screenshots/`** = proof of deployment (URLs, dashboards, agent responses).
